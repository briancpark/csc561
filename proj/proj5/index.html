Hopper

An endless river-crossing game rendered entirely with hand-written WebGL2 — real-time shadow mapping, vertex-shader water, and a full offscreen post-processing pipeline. Hop as far as you can: dodge the traffic, ride the logs, and don't let the river carry you away.

Score 0 Best 0

Controls

↑↓←→ Hop (or WASD)
R Restart the run

Under the hood

Shadow mapping Depth-only pass from a texel-snapped orthographic sun, sampled with hardware-compared 3×3 PCF for soft edges
Vertex-shader water Sum-of-sines displacement with analytic normals, fresnel sky reflection, and sun glints — shadows land on the waves too
Lighting Hemisphere ambient plus Blinn-Phong directional sun, with exponential distance fog
Post-processing Scene renders into a 4× MSAA framebuffer, resolved and tonemapped with a vignette (and a desaturating death fade)
Particles GPU point sprites streamed through a dynamic buffer for splashes and landing dust
Procedural world Seeded lane generation with a guaranteed walkable corridor; every mesh is built in code from vertex-colored boxes (append ?seed=N for a reproducible run)
