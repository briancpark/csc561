Textures & Transparency

Texture mapping and alpha blending over a sky backdrop, with painter's-algorithm sorting for transparent surfaces.

Controls

ADWSQE Translate the view; hold Shift to rotate instead
←→↑↓ Select the previous / next triangle set or ellipsoid
Space Deselect the current model
K;OLIP Translate the selected model; hold Shift to rotate
B Toggle between modulated material blending and texture replace
Shift+1 Load the alternate scene
Esc / Backspace Reset the view / reset all model transforms
