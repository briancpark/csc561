Rasterization

Blinn–Phong-shaded triangle sets with an interactive camera and per-model transforms. Hold ! for the bonus scene — an image rebuilt from thousands of Delaunay triangles.

Controls

ADWSQE Translate the view (left / right / forward / back / up / down)
Shift+ADWS Rotate the view (yaw and pitch)
←→ Select and highlight the previous / next triangle set
Space Deselect and turn off the highlight
K;OLIP Translate the selected model along view X / Z / Y
Shift+K:OLIP Rotate the selected model (yaw / pitch / roll)
! Load the creative scene; keep pressing to spin it around Y
